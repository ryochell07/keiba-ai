## JRA公式サイトで取れるもの

- 過去結果: 1988年まで選択可能 (2018年のレースで結果と最終オッズを確認済み)
- 確定結果: 着順、タイム、着差、通過順、上がり、馬体重、確定人気、全券種の払戻
- 最終オッズ: 単勝、複勝、枠連、馬連、ワイド、馬単、三連複、三連単 (1券種1リクエスト)
- 発売中オッズ: 同じページ構造で、開催日に取得時刻つきで蓄積

実装は3秒に1リクエスト以下。403/429を受けたらその実行を停止し、再試行で押し切りません。
URLのチェック値はサイトが返すリンクと検索ページの表をそのまま使い、総当たりしません。

## 地方競馬の方針

公式の説明書 (`/pdf/manual/data_pdf_manual.pdf`) によると、月次ZIP (レース情報は1998年1月以降、オッズは2026年3月以降) と
当日ZIP (約2分ごと更新、中間オッズを含む) が提供されています。

`robots.txt` は `/KeibaWeb/DataDownload/` を禁止していますが、協会の回答に基づき `config/sources.yaml` の `permission` に許諾を記録して取得します。
回答は口頭なので、**条件が変わったら `automated_fetch: false` と `permission.status: none` に戻してください**。HTTPクライアントが取得を止めます。

- 取得頻度: 確定済みの月は1回だけ、更新中の月は1日1回、当日ファイルは30分に1回 (説明書の目安は2分に1回)
- 間隔: 10秒に1リクエスト以上 (`robots.txt` の Crawl-delay に合わせる)
- 用途: 個人利用のみ。データの転載・再配布はしない

### 実ファイルと説明書の違い (2026年10月分で確認)

- 文字コードはUTF-8 BOM付き
- 競馬場名は「帯広」でなく「帯広ば」
- 払戻のヘッダは `馬複人気1` (説明書は全角の `馬複人気１`)
- ばんえいの馬場欄は水分量 (例: 1.2)。ばんえいは予測対象外

### オッズの保存量

月次のオッズZIPは月180万行前後あります。容量を抑えるため、古い月は単勝と複勝だけを保存します。
当日ファイルは発走前のレースだけを保存し、三連単などは発走60分前からのものに絞ります。

## データの取り扱い

- 取得データ、DB、生HTML、ZIP、CSVは `.gitignore` で除外し、リポジトリに入れません
- テストのフィクスチャはすべて架空データです
- クラウドに置く状態ファイルは AES-256-GCM で暗号化します
- 閲覧ページの予測データも暗号化し、合言葉がないと読めません
