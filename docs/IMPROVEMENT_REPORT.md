# 精度改善レポート (地方競馬、2026-11-06)

## 結論

- **採用:** 新モデルは現行より確かに改善しました (Log Loss 1.682 → 1.633)
- **未達:** 市場オッズには届いていません (確定オッズ 1.539)
- **未達:** 回収率100%を超える買い方は見つかっていません。62通りの戦略で合格はゼロです
- **未検証:** 発走前オッズでの評価はできていません。過去分が存在せず、蓄積はこれからです

詳細な数字は `docs/lab_summary.json` と、ダッシュボードの「モデル」タブにあります。

## 検証の進め方

| 期間 | 用途 |
|---|---|
| 2019-01〜2025-02 | 学習 |
| 2025-03〜2025-08 | 調整 (特徴量の採否、パラメータ) |
| 2025-09〜2026-02 | 選択 (調整に使っていない期間で手法を比較) |
| 2026-03〜2026-11 | 封鎖テスト (設定の確定後に1回だけ評価) |

### 検証の限界

1. **封鎖テストは完全な未使用ではありません。** 今回の作業の前に、合成方式を決めるためこの期間の結果を見ています。完全に未使用なのは 2026-11-06 以降に発走するレースです。
2. **市場との比較は確定オッズです。** 地方のオッズは2026年3月以降しかなく、発走前の時点のものは過去分が存在しません。確定オッズは発走直前までの情報を含むので、同じ時点の比較にはなりません。AI側は発走前の情報だけなので、この比較は市場に有利です。一方、**買い目の判定に確定オッズを使う部分は実運用より甘くなります。**
3. **市場融合の係数は封鎖テストの前半で推定しています。** オッズが他の期間にないためです。評価は後半だけで行いました。
4. **買い目の閾値は事前に選べていません。** 閾値を決める開発期間にオッズがないので、全閾値を並べて基準で判定しました。
5. **中央競馬は未評価です。** 過去データの取得中です。採用した設定は地方で決めたものです。

## 1. 現行AIの弱点分析

調整と選択の期間 (2025-03〜2026-02、13,373レース) で分析しました。ここでの「市場」は、オッズのない期間なので確定人気から作った代用です。オッズ帯別の分析は同じ理由でできていません。

| 弱点 | 数字 | 対応 |
|---|---|---|
| 人気馬を低く見る | 1番人気の予測勝率36.5% / 実際45.4% | AIは市場の評価を知らない。融合で補う |
| 人気薄を高く見る | 10番人気以下の予測1.3% / 実際0.5%、回収率45.6% | 同上 |
| 確定人気の順位だけに負ける | Log Loss AI 1.698 / 代用 1.635 | 特徴量の強化で 1.597 / 1.602 まで改善 (選択期間) |
| 市場より低く評価した馬 | 回収率60.1% | 妥当。AIが下げた馬は実際に買うべきでない |
| 市場より高く評価した馬 | 回収率77.3%、予測12.2% / 実際9.2% | 期待値が過大に出る主因 |

競馬場別、距離別、馬場別の校正の崩れは小さく、どの条件でも回収率は控除率の影響から抜けていません。
天候の小雪、雪などはサンプルが少なく、判断できません。クラス別の3.0で回収率122.8%がありますが82レースで、偶然と区別できません。

**分析の過程で、私の実装の不備も見つかりました。** 地方の通過順を読み取れておらず、脚質の特徴量が全部欠けていました。修正して、全レースを再取り込みしました (通過順の入力率は約89%)。

### 期待値の計算についての所見

- 計算式に誤りは見つかっていません。単勝の期待値帯別は、0.8未満が62%、0.8〜1.0が79%、1.0〜1.2が95%と順に上がり、推定は方向として機能しています

- 取消馬のオッズが残るレースは市場確率が歪むので、評価から除きました
- ダッシュボードでは、期待値プラスの買い目に「同条件の過去回収率」を表示します

## 11. 採用モデルとその理由

- **方式:** LightGBM (Plackett-Luce目的関数)、Optunaで調整したパラメータ
- **特徴量:** 既存 + スピード指数、条件別能力、相手関係、騎手・調教師
- **学習期間:** 2019年以降
- **発売中の確率:** AIと単勝オッズの合成
- **校正、条件別モデル:** なし

理由は、未使用の選択期間と封鎖テストの両方で、Log LossとBrierが現行より確かに改善したためです。

## 12. 今後の改善課題

1. **発走前オッズの蓄積 (最優先):** 実際に買える時点のオッズで評価しないと、期待値戦略の判定はできません。数週間から数か月分が必要です
2. **未使用レースでの追跡:** 2026-11-06 以降の予測と結果を照合し、三連単の本命などの再現を確かめます
3. **中央競馬の評価:** 過去データの取得完了後に同じ手順で検証します
4. **組み合わせ券種の確率:** 過大評価の改善。券種ごとの補正や、市場オッズそのものの活用を検討します
5. **未取得の情報:** 調教、血統の深掘り、馬主、騎手の乗り替わり事情など、市場が織り込んでいる情報への接近です

市場が織り込んでいない情報を得られない限り、公開データだけで控除率 (約20〜27.5%) を超えるのは難しいのが現時点の見立てです。
